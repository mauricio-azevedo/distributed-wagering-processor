# Decisions

Templates for a new ADR. The minimal ones serve most decisions; reach for a full one when there are more
than two options, drivers worth recording, or people to consult or inform. The explained variants carry
the same sections with guidance inline; the bare ones carry only the headings.

- [adr-template-bare-minimal.md](adr-template-bare-minimal.md): the mandatory sections, empty.
- [adr-template-minimal.md](adr-template-minimal.md): the mandatory sections, with explanations.
- [adr-template-bare.md](adr-template-bare.md): all sections, empty.
- [adr-template.md](adr-template.md): all sections, with explanations.

The last Consequences bullet says what would make the decision worth revisiting. The templates come from
MADR 4.0.0 and keep its line wrapping.

The MADR documentation is at <https://adr.github.io/madr/>; general information about ADRs is at
<https://adr.github.io/>.
